## Run app & Install

### 1. Create env

    python3 -m venv env

###

### 2. Activate env

Firstly, open Terminal and run:

- **With macOS/Linux:**
  ```bash
  source env/bin/activate
  ```
- **With window:**
  ```bash
  .\env\Scripts\activate
  ```

### 3. Install library

    pip install -r requirements.txt

### 4. Run app

    python app.py

###
